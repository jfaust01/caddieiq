================================================================================
GOVERNANCE ENFORCEMENT
================================================================================

Build Lifecycle (enforced by repository):
  create() → DEVELOPMENT
      ↓
  promoteToCandidate() → CANDIDATE
      ↓
  promoteToActive() → ACTIVE
      (prior ACTIVE builds → RETIRED)
      ↓
  retire() → RETIRED

Status Validation:
  • No skipping stages (must go dev→candidate→active)
  • No demoting from active (must retire)
  • No promoting without validation (caller's responsibility)

Version Validation:
  • Semantic versioning enforced (MAJOR.MINOR.PATCH)
  • No duplicate versions allowed
  • Version progression validated

================================================================================
REPRODUCIBILITY GUARANTEE
================================================================================

Every build includes:
  • buildHash (SHA256 of manifest)
  • buildManifestJson (all versions, feature set, formula, etc.)
  • Status tracking (when promoted, retired, etc.)
  • CreatedBy (who created it)

Result: Every prediction from a build is recreatable:
  1. Find score by scoreId
  2. Get score.buildId
  3. Retrieve build manifest
  4. All input versions available in manifest
  5. Recreate prediction with identical inputs
  → Same result guaranteed (reproducibility proven)
