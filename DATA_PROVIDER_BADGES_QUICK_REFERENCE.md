# Data Provider Badges — Quick Reference

## Overview

The Data Management > Platform Inventory table now displays a **Provider** badge for every table, showing where the data originates.

## Provider Badge Guide

| Badge | Provider | Tables | Purpose |
|-------|----------|--------|---------|
| 🟦 | **SportsDataIO** | 13 | Tournament, player, betting, fantasy, news data |
| 🟩 | **GolfCourseAPI** | 11 | Course layouts, holes, tees, coordinates |
| 🟨 | **Internal** | 11 | Generated intelligence, reference data, auth |
| 🟪 | **Multiple** | 4 | Data from 2+ providers (e.g., odds, weather) |

## How Badges Work

1. **Visual Badge**: Color-coded emoji + label displayed in the table
2. **Tooltip**: Hover for a description of the provider's data
3. **Configuration-Driven**: Mapping lives in `lib/data-coverage/provider-config.ts`

## For Administrators

Use provider badges to:
- **Track data ownership**: Know which system to investigate if data is missing
- **Distinguish sources**: Import vs. generated vs. calculated
- **Understand dependencies**: See which tables depend on external providers
- **Debug issues**: Route problems to the correct upstream provider

## For Developers

### Adding a New Table

1. Add the table to `lib/data-coverage/inventory.ts` (REGISTRY)
2. Add mapping to `lib/data-coverage/provider-config.ts` (PROVIDER_CONFIG)
3. The badge will appear automatically — no component changes needed

**Example:**

```typescript
// provider-config.ts
export const PROVIDER_CONFIG: Record<string, DataProvider> = {
  // ... existing entries
  new_table_name: "sportsdataio",  // ← Add here
}
```

### Adding a New Provider

1. Add to `DataProvider` type in `lib/data-coverage/types.ts`
2. Add to `PROVIDER_INFO` in `lib/data-coverage/provider-config.ts`
3. Add emoji, color, and tooltip

**Example:**

```typescript
export type DataProvider = "sportsdataio" | "golfcourseapi" | "internal" | "multiple" | "newprovider"

export const PROVIDER_INFO: Record<DataProvider, ProviderInfo> = {
  newprovider: {
    label: "New Provider",
    badge: "🟧",  // Pick an emoji
    tooltip: "Description of what this provider supplies.",
    color: "bg-orange-500/12 text-orange-600 dark:text-orange-400",
  },
}
```
